Chào mừng đến Chốt Đơn Live

Cài đặt 1 lần cho máy này. Dữ liệu đơn hàng của shop bạn lưu trong database MongoDB của riêng bạn.

1. Kết nối database (MongoDB Atlas)
Chưa có? Hướng dẫn tạo miễn phí (5 phút)
  1. Vào mongodb.com/cloud/atlas, đăng ký tài khoản miễn phí.
  2. Tạo cluster gói M0 (Free), chọn vùng Singapore cho nhanh.
  3. Database Access → Add New Database User → đặt tên + mật khẩu mạnh.
  4. Network Access → Add IP Address → Allow access from anywhere (0.0.0.0/0).
  5. Bấm Connect → Drivers → copy chuỗi mongodb+srv://…, thay <db_password> bằng mật khẩu ở bước 3.
Chuỗi này được mã hoá và chỉ lưu trên máy này. Không gửi cho ai khác.
2. Máy in nhiệt
Không thấy máy in? Cắm USB, bật máy in, cài driver rồi bấm "Làm mới". Có thể để trống và chọn sau.
